# TARIQ Taxi Zentrale App

Gemeinsame interne Plattformbasis für Büro, Disposition und Fahrer.

## Gemeinsame Basis mit TARIQ Fahrdienst
- Rollen: Admin, Büro, Fahrer
- Live-Disposition
- Fahrer-Web-App
- Statuskette: geplant -> auf dem Weg -> angekommen -> Fahrt starten -> Fahrt beenden
- Fahrzeug- und Fahrerzuordnung
- Kundenverwaltung
- Termin-/Auftragsverwaltung
- Fahrzeugverwaltung
- Personal
- Rechnungen, Buchhaltung und Berichte
- Dokumente, Nachrichten, PWA und Docker-Deployment

## Taxi-spezifische Erweiterungen
- Taxi
- Großraumtaxi
- Flughafentransfer
- Kurierfahrt
- Rollstuhlfahrt
- Krankenfahrten
- Taxitarife / Taxameterdaten
- Bar, Karte, Rechnung, Gutschein
- Zentrale/Spontanaufträge und Vorbestellungen

Produktive App-Adresse: https://app.tariq-taxizentrale.de

Die technische Basis wird bewusst parallel zu fahrdienstapp gehalten, damit gemeinsame Funktionen nicht später neu entwickelt werden müssen.
